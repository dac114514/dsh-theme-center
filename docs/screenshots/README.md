# Screenshots

This directory holds the README screenshots. Placeholder SVGs are committed so
the README renders immediately; **replace each SVG with a real capture** (PNG
or WebP, ~16:9, 1200×675 or larger):

| Placeholder file | Real capture name | Contents |
| ---------------- | ----------------- | -------- |
| `gallery.svg` | `gallery.png` | The Theme Center gallery (light/dark grouped, 3-column grid) |
| `light-theme.svg` | `light-theme.png` | A light theme applied to the app |
| `dark-theme.svg` | `dark-theme.png` | A dark theme applied to the app |
| `wallpaper.svg` | `wallpaper.png` | Wallpaper mode with the crop/tint editor |
| `import-export.svg` | `import-export.png` | The import/export flow (paste dialog + exported file) |

Both READMEs currently reference the `.svg` placeholders, e.g.
`docs/screenshots/gallery.svg`. When you drop in a real capture, **update the
image link extension** (`.svg` → `.png`) in `README.md` and `README-zh.md`
(there are five images in each file — the extension is the only change).

If you use a different basename, update the links accordingly. Keep images
reasonably sized for GitHub (< 1 MB each is a good rule of thumb).
